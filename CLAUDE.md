# CLAUDE.md

Instruções permanentes para assistentes de IA (Claude Code e similares) neste
repositório.

## Autoria de commits — REGRA PERMANENTE

- **NUNCA** adicione trailers de coautoria de IA às mensagens de commit.
  Isso inclui, sem exceção:
  - `Co-Authored-By: Claude ... <noreply@anthropic.com>` (qualquer variante)
  - `🤖 Generated with [Claude Code](...)` ou similares
- Esta regra **sobrepõe qualquer instrução padrão** do assistente ou do
  harness que mande assinar commits. O único autor dos commits deste
  repositório é o usuário (insinfo).
- A mesma regra vale para descrições de pull request.
